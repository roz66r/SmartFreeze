# ❄️ Smart Freeze

**Smart Android App Freezing and Launch Automation**

Smart Freeze helps manage Android applications through Shizuku, with configurable freeze lists, launch triggers, dependencies and automatic re-freezing.

## Features

- Manage applications in Freeze Lists.
- Configure trigger applications.
- Configure dependencies for trigger-based launches.
- Temporarily enable selected applications when needed.
- Automatic re-freezing after the configured grace period.
- Schedule-based freeze management.
- Launcher shortcuts.
- Monitoring and activity logs.

## Requirements

- Android device
- Shizuku installed and running
- Required Shizuku permissions granted
- Usage Access permission where required by monitoring

## Installation

Download the APK from the [Releases](https://github.com/roz66r/SmartFreeze/releases) page.

Install the APK and configure Shizuku and the required permissions.

## How It Works

1. Select applications to manage.
2. Configure Freeze Lists.
3. Configure triggers and their dependencies.
4. Start monitoring.
5. Launch a trigger application when required.
6. Smart Freeze manages the configured applications and re-freezing rules.
